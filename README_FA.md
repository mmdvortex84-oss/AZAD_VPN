# ® AZAD VPN — نسخهٔ بومی اولیه (مرحلهٔ ۱)

این پروژه یک برنامهٔ اندرویدی بومی است؛ دیگر به WebView و فایل HTML برای نمایش صفحهٔ اصلی وابسته نیست.

## امکانات پیاده‌شده در این مرحله
- رابط تیره با تم‌های آبی، سبز، بنفش، مشکی/طلایی و قرمز
- زبان فارسی و انگلیسی؛ انتخاب‌ها در گوشی ذخیره می‌شوند
- افزودن لینک‌های VLESS، VMess، Trojan، Shadowsocks، Hysteria2 و TUIC
- واردکردن فایل یا متن کانفیگ؛ لینک اشتراک HTTP(S) هم دریافت و خط‌به‌خط بررسی می‌شود
- فهرست پروفایل‌ها، انتخاب یک سرور، حذف تکرارها
- آزمایش زمان پاسخ TCP برای host:port و نمایش آن در فهرست
- وابستگی کتابخانهٔ libbox اضافه شده تا مرحلهٔ بعد موتور sing-box را یکپارچه کنیم

## محدودیت مهم — اتصال واقعی هنوز پیاده‌سازی نشده
این مرحله هنوز `VpnService` و lifecycle موتور sing-box را کامل متصل نکرده است. دکمهٔ اتصال عمداً پیام شفاف می‌دهد و **وضعیت اتصال یا حاشیهٔ سبز جعلی نشان نمی‌دهد**. زمان پاسخ TCP هم پینگ واقعی داخل تونل VPN نیست؛ تنها رسیدن اتصال TCP به host:port را اندازه می‌گیرد. پشتیبانی واقعی از فایل‌های OpenVPN/WireGuard نیز نیازمند ادغام و آزمون موتور مربوط است.

## ساخت APK با GitHub Actions از گوشی
1. یک مخزن تازه در GitHub بساز.
2. همهٔ محتوای این پوشه را در ریشهٔ مخزن بارگذاری کن (خود پوشهٔ `AZAD_Android` نباید یک لایهٔ اضافی داخل مخزن بماند).
3. در GitHub به تب **Actions** برو و workflow **Build AZAD VPN APK** را اجرا کن.
4. پس از موفقیت، پایین صفحهٔ اجرای workflow از بخش **Artifacts** فایل `AZAD-VPN-debug-apk` را بگیر.

## مرحلهٔ بعد
باید `libbox` را به سرویس اندرویدی VPN (VpnService) وصل کنیم، مجوز VPN اندروید را درخواست کنیم و چرخهٔ شروع/توقف، آمار ترافیک و خطاها را از موتور واقعی بخوانیم. تا آن مرحله، برنامه را VPN فعال تلقی نکن.
